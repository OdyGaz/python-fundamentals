## Commit 2: Τεχνικό Λεξικό: Chapter 1-3

### 1. Βασικοί Όροι (Key Terms)

| Όρος (English) | Περιγραφή |
| :--- | :--- |
| **Abstraction** | Η διαδικασία εστίασης στα σημαντικά χαρακτηριστικά αγνοώντας τις περιττές λεπτομέρειες. |
| **Algorithm** | Μια λεπτομερής ακολουθία βημάτων για την εκτέλεση μιας διαδικασίας· μια "συνταγή". |
| **Assignment** | Η διαδικασία απόδοσης μιας τιμής σε μια μεταβλητή μέσω του συμβόλου `=`. |
| **Binary** | Το δυαδικό σύστημα αρίθμησης (βάση-2) που χρησιμοποιεί μόνο τα ψηφία 0 και 1. |
| **CPU (Central Processing Unit)** | Ο "εγκέφαλος" του υπολογιστή όπου εκτελούνται οι αριθμητικές και λογικές πράξεις. |
| **Compiler** | Πρόγραμμα που μεταφράζει ολόκληρο τον πηγαίο κώδικα μιας γλώσσας υψηλού επιπέδου σε γλώσσα μηχανής. |
| **Computer Science** | Η μελέτη του τι μπορεί να υπολογιστεί μέσω σχεδιασμού, ανάλυσης και πειραματισμού. |
| **Data Type** | Ο τύπος των δεδομένων (π.χ. `int`, `float`) που καθορίζει τις δυνατές τιμές και πράξεις. |
| **Debugging** | Η διαδικασία εντοπισμού και διόρθωσης σφαλμάτων (bugs) σε ένα πρόγραμμα. |
| **Expression** | Ένα τμήμα κώδικα που παράγει ή υπολογίζει νέα δεδομένα. |
| **Fetch-Execute Cycle** | Η διαδικασία ανάκτησης, αποκωδικοποίησης και εκτέλεσης εντολών από την CPU. |
| **Hardware** | Τα φυσικά εξαρτήματα ενός υπολογιστικού συστήματος. |
| **Identifier** | Το όνομα που δίνεται σε μια οντότητα του προγράμματος (μεταβλητή, συνάρτηση κ.λπ.). |
| **Interpreter** | Πρόγραμμα που αναλύει και εκτελεί τον κώδικα εντολή προς εντολή, προσομοιώνοντας έναν υπολογιστή. |
| **IPO Pattern** | Μοντέλο προγραμματισμού: Είσοδος (Input), Επεξεργασία (Process), Έξοδος (Output). |
| **Literal** | Η αναπαράσταση μιας συγκεκριμένης τιμής απευθείας στον κώδικα (π.χ. ο αριθμός 32). |
| **Machine Language** | Η χαμηλού επιπέδου γλώσσα (δυαδική) που κατανοεί άμεσα το υλικό του υπολογιστή. |
| **RAM (Main Memory)** | Πτητική μνήμη όπου αποθηκεύονται τα προγράμματα και τα δεδομένα κατά την εκτέλεσή τους. |
| **Secondary Memory** | Μη πτητική αποθήκευση (π.χ. σκληροί δίσκοι, flash) για μόνιμη διατήρηση πληροφοριών. |
| **Software** | Τα προγράμματα που καθορίζουν τη λειτουργία του υλικού (hardware). |
| **Source Code** | Το κείμενο ενός προγράμματος γραμμένο σε μια γλώσσα υψηλού επιπέδου. |
| **Syntax** | Οι κανόνες που καθορίζουν τη μορφή και τη δομή των εντολών μιας γλώσσας. |

---

### 2. Συναρτήσεις, Εντολές ή Εργαλεία (Functions & Commands)

| Εντολή / Συνάρτηση | Λειτουργία |
| :--- | :--- |
| **`abs(x)`** | Επιστρέφει την απόλυτη τιμή του αριθμού `x`. |
| **`def`** | Λέξη-κλειδί για τον ορισμό μιας νέας συνάρτησης (π.χ. `def main():`). |
| **`eval(input())`** | Χρησιμοποιείται για τη λήψη αριθμητικής εισόδου (αξιολογεί το κείμενο ως έκφραση). |
| **`float(x)`** | Μετατρέπει την τιμή `x` σε αριθμό κινητής υποδιαστολής. |
| **`for <var> in <seq>:`** | Εντολή επανάληψης (definite loop) για επεξεργασία μιας ακολουθίας τιμών. |
| **`IDLE`** | Το ολοκληρωμένο περιβάλλον ανάπτυξης (IDE) που συνοδεύει την Python. |
| **`input(prompt)`** | Εμφανίζει ένα μήνυμα και λαμβάνει είσοδο από τον χρήστη ως κείμενο (string). |
| **`int(x)`** | Μετατρέπει την τιμή `x` σε ακέραιο αριθμό. |
| **`math.sqrt(x)`** | Συνάρτηση από τη βιβλιοθήκη `math` για τον υπολογισμό της τετραγωνικής ρίζας. |
| **`print()`** | Εμφανίζει κείμενο ή τιμές στην έξοδο (οθόνη). |
| **`range(n)`** | Παράγει μια ακολουθία αριθμών από το 0 έως το n-1. |
| **`round(x)`** | Στρογγυλοποιεί έναν αριθμό στον πλησιέστερο ακέραιο. |

---

### 3. Τελεστές, Σύμβολα ή Ειδική Σημειογραφία (Operators & Symbols)

| Σύμβολο | Σημασία / Χρήση |
| :--- | :--- |
| **`+`** | Πρόσθεση αριθμών ή Συνένωση (concatenation) συμβολοσειρών. |
| **`-`** | Αφαίρεση αριθμών. |
| **`*`** | Πολλαπλασιασμός αριθμών. |
| **`/`** | Διαίρεση (float division) - δίνει πάντα αποτέλεσμα με δεκαδικά. |
| **`//`** | Διαίρεση ακεραίων (integer division) - δίνει μόνο το ακέραιο μέρος. |
| **`%`** | Υπόλοιπο διαίρεσης (remainder/modulo). |
| **`**`** | Ύψωση σε δύναμη (exponentiation). |
| **`=`** | Τελεστής ανάθεσης (assignment) τιμής σε μεταβλητή. |
| **`==`** | Έλεγχος ισότητας (relational operator). |
| **`#`** | Έναρξη σχολίου (comment) - αγνοείται από τον διερμηνέα της Python. |
| **`>>>`** | Python prompt - υποδεικνύει ότι ο διερμηνέας είναι έτοιμος για εντολή. |
| **`\n`** | Χαρακτήρας νέας γραμμής (newline character). |
| **`""` ή `''`** | Οριοθέτες συμβολοσειρών (string literals). |
