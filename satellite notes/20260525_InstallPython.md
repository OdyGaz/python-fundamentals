Η εγκατάσταση της Python στα Windows και η προσθήκη της στο PATH είναι μια απλή διαδικασία. Ο πιο εύκολος τρόπος είναι να το κάνετε αυτόματα κατά τη διάρκεια της εγκατάστασης, αλλά παρακάτω περιγράφεται και ο χειροκίνητος τρόπος σε περίπτωση που χρειαστεί.

---

### Μέθοδος 1: Αυτόματη προσθήκη στο PATH (Συνιστώμενος τρόπος)

1. **Λήψη της Python:**
   * Επισκεφθείτε την επίσημη ιστοσελίδα [python.org](https://www.python.org/downloads/).
   * Κατεβάστε την τελευταία έκδοση για Windows (κουμπί *Download Python*).

2. **Εγκατάσταση:**
   * Εκτελέστε το αρχείο εγκατάστασης (`.exe`) που κατεβάσατε.
   * **Πολύ Σημαντικό:** Στο κάτω μέρος του πρώτου παραθύρου που θα εμφανιστεί, επιλέξτε το κουτάκι που λέει **"Add python.exe to PATH"** (ή "Add Python to PATH"). Αν δεν το επιλέξετε, η Python δεν θα αναγνωρίζεται από το cmd.
   * Πατήστε **"Install Now"** και περιμένετε να ολοκληρωθεί η εγκατάσταση.

---

### Μέθοδος 2: Χειροκίνητη προσθήκη στο PATH (Αν έχετε ήδη εγκαταστήσει την Python)

Αν έχετε ήδη εγκαταστήσει την Python αλλά ξεχάσατε να επιλέξετε το κουτάκι για το PATH, ακολουθήστε τα εξής βήματα:

1. **Βρείτε τη διαδρομή (Path) εγκατάστασης της Python:**
   * Συνήθως η Python εγκαθίσταται στην εξής διαδρομή (αντικαταστήστε το `Username` με το δικό σας όνομα χρήστη στα Windows και το `Python3x` με την έκδοση που έχετε, π.χ. `Python312`):
     `C:\Users\Username\AppData\Local\Programs\Python\Python3x`
   * *Σημείωση: Ο φάκελος AppData είναι κρυφός. Μπορείτε να τον εμφανίσετε ενεργοποιώντας τα "Κρυφά στοιχεία" (Hidden items) στην προβολή του File Explorer, ή να πατήσετε `Win + R`, να γράψετε `%localappdata%\Programs\Python` και να πατήσετε Enter για να μεταφερθείτε απευθείας εκεί.*

2. **Αντιγράψτε τις διαδρομές:**
   Θα χρειαστείτε δύο διαδρομές:
   * Την κύρια διαδρομή: `C:\Users\Username\AppData\Local\Programs\Python\Python3x\`
   * Τη διαδρομή των Scripts: `C:\Users\Username\AppData\Local\Programs\Python\Python3x\Scripts\`

3. **Επεξεργασία των Μεταβλητών Περιβάλλοντος:**
   * Στην αναζήτηση των Windows, πληκτρολογήστε **"Μεταβλητές περιβάλλοντος"** (Environment Variables) και επιλέξτε το **"Επεξεργασία των μεταβλητών περιβάλλοντος του συστήματος"** (Edit the system environment variables).
   * Στο παράθυρο που θα ανοίξει, κάντε κλικ στο κουμπί **"Μεταβλητές Περιβάλλοντος..."** (Environment Variables...) στο κάτω μέρος.
   * Στο πάνω πλαίσιο ("Μεταβλητές χρήστη" ή User variables), βρείτε τη μεταβλητή με το όνομα **`Path`** (ή `PATH`), επιλέξτε τη και κάντε κλικ στο **"Επεξεργασία..."** (Edit...).
   * Κάντε κλικ στο **"Δημιουργία"** (New) και επικολλήστε την κύρια διαδρομή της Python.
   * Κάντε ξανά κλικ στο **"Δημιουργία"** (New) και επικολλήστε τη διαδρομή των `Scripts`.
   * Πατήστε **OK** σε όλα τα παράθυρα για να αποθηκευτούν οι αλλαγές.

---

### Έλεγχος και Εκτέλεση αρχείων `.py` από το CMD

Αφού ολοκληρώσετε τα παραπάνω βήματα (και έχετε κλείσει τυχόν ήδη ανοιχτά παράθυρα CMD για να ανανεωθούν οι αλλαγές):

1. **Έλεγχος εγκατάστασης:**
   * Ανοίξτε τη Γραμμή Εντολών (Command Prompt / cmd).
   * Πληκτρολογήστε την εντολή:
     ```cmd
     python --version
     ```
   * Αν εμφανιστεί η έκδοση της Python (π.χ. `Python 3.12.x`), η εγκατάσταση και η ρύθμιση του PATH ήταν επιτυχείς.

2. **Εκτέλεση ενός αρχείου `.py`:**
   * Στο CMD, μεταβείτε στον φάκελο όπου έχετε αποθηκεύσει το αρχείο σας χρησιμοποιώντας την εντολή `cd` (π.χ. `cd Desktop` ή `cd Documents`).
   * Εκτελέστε το αρχείο πληκτρολογώντας `python` ακολουθούμενο από το όνομα του αρχείου:
     ```cmd
     python to_arxeio_mou.py
     ```
