Για να δημιουργήσετε ένα αρχείο **GIF** χρησιμοποιώντας τη βιβλιοθήκη **Manim** της Python (ιδιαίτερα τη σύγχρονη έκδοση Manim Community), μπορείτε να το κάνετε με έναν από τους παρακάτω τρόπους, ανάλογα με το πώς εκτελείτε τον κώδικά σας.

---

### 1. Μέσω της γραμμής εντολών (CLI)
Αυτός είναι ο πιο συνηθισμένος τρόπος. Κατά την εκτέλεση της εντολής στο τερματικό, προσθέτετε την παράμετρο `--format gif`:

```bash
manim --format gif file.py MyScene
```

Αν θέλετε να συνδυάσετε την εξαγωγή με χαμηλή ποιότητα (για πιο γρήγορο render κατά τις δοκιμές) και αυτόματη προεπισκόπηση, μπορείτε να γράψετε:
```bash
manim -ql -p --format gif file.py MyScene
```

*(Σημείωση: Σε παλαιότερες εκδόσεις της Manim χρησιμοποιούνταν η παράμετρος `-i` ή `--save_as_gif`. Αν και σε ορισμένες εκδόσεις λειτουργεί ακόμα, πλέον θεωρείται ξεπερασμένη).*

---
Για να δημιουργήσετε ένα GIF **υψηλής ποιότητας**, μπορείτε να χρησιμοποιήσετε τη σημαία (flag) **`-qh`** (High Quality - 1080p στα 60fps). 

Η εντολή στο τερματικό διαμορφώνεται ως εξής:

```bash
manim -qh --format gif file.py MyScene
```

Αν θέλετε ακόμα υψηλότερη ανάλυση (π.χ. 4K), μπορείτε να χρησιμοποιήσετε τη σημαία **`-qk`** (4K Quality):

```bash
manim -qk --format gif file.py MyScene
```

---

### ⚠️ Μια σημαντική λεπτομέρεια για τα GIF υψηλής ποιότητας
Το format των GIF δεν διαθέτει την αποδοτική συμπίεση των σύγχρονων αρχείων βίντεο (όπως το MP4). Αυτό σημαίνει ότι ένα GIF στα **1080p με 60 frames per second (fps)** μπορεί να έχει **τεράστιο μέγεθος αρχείου** (πολλά Megabytes), καθιστώντας δύσκολη την κοινοποίησή του στο διαδίκτυο ή σε πλατφόρμες επικοινωνίας.

**Συμβουλές για ισορροπημένη ποιότητα και μέγεθος:**

1. **Μείωση των FPS:** Μπορείτε να διατηρήσετε την υψηλή ανάλυση (1080p) αλλά να μειώσετε τα frames ανά δευτερόλεπτο (π.χ. στα 30 ή 15 fps) για να «ελαφρύνει» το αρχείο, χρησιμοποιώντας την παράμετρο `--fps`:
   ```bash
   manim -qh --fps 30 --format gif file.py MyScene
   ```
2. **Χρήση Medium Quality (`-qm`):** Η μεσαία ποιότητα (720p στα 30fps) είναι συνήθως η χρυσή τομή για GIF που προορίζονται για το web:
   ```bash
   manim -qm --format gif file.py MyScene
   ```

### 2. Μέσα από τον κώδικα Python (Προγραμματιστικά)
Αν προτιμάτε να ορίσετε τη μορφή εξαγωγής απευθείας μέσα στο script σας, μπορείτε να τροποποιήσετε το αντικείμενο `config` της βιβλιοθήκης:

```python
from manim import *

# Ρύθμιση για εξαγωγή σε GIF αντί για MP4
config.format = "gif"

class MyScene(Scene):
    def construct(self):
        circle = Circle()
        self.play(Create(circle))
```

---

### 3. Μέσα από Jupyter Notebook
Αν χρησιμοποιείτε περιβάλλον Jupyter Notebook, μπορείτε να προσθέσετε την παράμετρο `--format gif` στο magic command:

```python
%%manim -ql --format gif MyScene

class MyScene(Scene):
    def construct(self):
        circle = Circle()
        self.play(Create(circle))
```

### Πού αποθηκεύεται το GIF;
Το παραγόμενο GIF θα αποθηκευτεί στον ίδιο φάκελο όπου αποθηκεύονται συνήθως και τα αρχεία `.mp4`, στη διαδρομή:
`media/videos/<όνομα_αρχείου>/<ποιότητα>/MyScene.gif`
