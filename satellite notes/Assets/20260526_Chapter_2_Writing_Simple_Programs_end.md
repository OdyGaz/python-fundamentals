#### **Ερώτηση 3:**
Ποιος είναι ο ρόλος και η χρήση της παραμέτρου `end` στη συνάρτηση εξόδου `print()`;

**Απάντηση/Λύση:**
Η παράμετρος `end` καθορίζει τον χαρακτήρα που θα εκτυπωθεί στο τέλος της εντολής `print()`. 
* **Προεπιλογή:** Αν δεν οριστεί, η Python χρησιμοποιεί τον χαρακτήρα αλλαγής γραμμής `\n` (`end="\n"`), στέλνοντας την επόμενη εκτύπωση στην από κάτω γραμμή.
* **Προσαρμογή:** Μπορούμε να αλλάξουμε αυτή τη συμπεριφορά για να κρατήσουμε τις εκτυπώσεις στην ίδια γραμμή ή να εισάγουμε διαχωριστικά σύμβολα.

*Παραδείγματα εφαρμογής:*
```python
# 1. Εκτύπωση στην ίδια γραμμή με κενό διάστημα:
print("Γεια", end=" ")
print("κόσμε")  # Έξοδος: Γεια κόσμε

# 2. Εκτύπωση χωρίς κανένα κενό (συνένωση):
print("Super", end="")
print("man")    # Έξοδος: Superman

# 3. Χρήση ειδικού διαχωριστικού:
print("Α", end=" - ")
print("Β")      # Έξοδος: Α - Β
```
