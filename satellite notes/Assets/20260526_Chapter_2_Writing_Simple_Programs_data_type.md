#### **Ερώτηση 5:**
Με ποιους τρόπους μπορούμε να προσδιορίσουμε ή να ελέγξουμε τον τύπο δεδομένων μιας μεταβλητής στην Python;

**Απάντηση/Λύση:**
Υπάρχουν δύο βασικές ενσωματωμένες μέθοδοι:

**Μέθοδος Α: Η συνάρτηση `type()`**
Επιστρέφει την κλάση (τύπο) της μεταβλητής. Χρησιμοποιείται κυρίως για γρήγορη επιθεώρηση ή εκτύπωση.
```python
x = [1, 2, 3]
print(type(x))  # Έξοδος: <class 'list'>
```

**Μέθοδος Β: Η συνάρτηση `isinstance(variable, type)`**
Ελέγχει αν μια μεταβλητή ανήκει σε έναν συγκεκριμένο τύπο δεδομένων και επιστρέφει Boolean τιμή (`True` ή `False`). Θεωρείται η βέλτιστη πρακτική για ελέγχους ροής (π.χ. σε δομές `if`).
```python
x = 10
if isinstance(x, int):
    print("Είναι ακέραιος")  # Θα εκτελεστεί
```
