Η Manim δεν λειτουργεί όπως τα συνηθισμένα προγράμματα της Python. Όταν εκτελείτε το αρχείο απλώς με την εντολή `python filename.py`, η Python ορίζει την κλάση `SimpleCircle` αλλά δεν εκκινεί τη μηχανή απόδοσης (rendering engine) της Manim για να δημιουργήσει και να προβάλει το βίντεο.

Για να εμφανιστεί το βίντεο, πρέπει να εκτελέσετε τον κώδικα με έναν από τους παρακάτω τρόπους, ανάλογα με το περιβάλλον εργασίας σας:

---

### Τρόπος 1: Μέσω του Τερματικού (Command Line)
Αυτός είναι ο τυπικός τρόπος λειτουργίας της Manim. 

1. Αποθηκεύστε τον κώδικά σας σε ένα αρχείο, για παράδειγμα με το όνομα `my_scene.py`.
2. Ανοίξτε το τερματικό (ή τη γραμμή εντολών) στον φάκελο που βρίσκεται το αρχείο.
3. Πληκτρολογήστε την εξής εντολή:

```bash
manim -pql my_scene.py SimpleCircle
```

**Τι σημαίνουν οι παράμετροι:**
*   `-p` (preview): Λέει στη Manim να ανοίξει αυτόματα το βίντεο μόλις ολοκληρωθεί η δημιουργία του.
*   `-q` (quality): Ορίζει την ποιότητα.
*   `l` (low quality): Παράγει βίντεο ανάλυσης $480\text{p}$ στα $15\text{ fps}$ για γρήγορο rendering κατά τη διάρκεια των δοκιμών. (Εναλλακτικά, μπορείτε να χρησιμοποιήσετε `-pqm` για $720\text{p}$ ή `-pqh` για υψηλή ανάλυση $1080\text{p}$).

---

### Τρόπος 2: Απευθείας μέσα από το IDE (VS Code, PyCharm, IDLE κ.λπ.)
Αν θέλετε να πατάτε απλώς το κουμπί "Run" (Εκτέλεση) στο περιβάλλον ανάπτυξής σας, μπορείτε να προσθέσετε ένα μπλοκ ελέγχου στο τέλος του αρχείου σας, το οποίο καλεί αυτόματα τη Manim μέσω του συστήματος:

```python
from manim import *

class SimpleCircle(Scene):
    def construct(self):
        # Δημιουργία κύκλου με ακτίνα 1.5
        circle = Circle(radius=1.5, color=RED)
        
        # Εμφάνιση του κύκλου στην οθόνη
        self.play(Create(circle))
        self.wait(1)

# Προσθέστε αυτό το τμήμα στο τέλος του αρχείου:
if __name__ == "__main__":
    import os
    # Εκτελεί την εντολή render αυτόματα για το συγκεκριμένο αρχείο
    os.system(f"manim -pql {__file__} SimpleCircle")
```

---

### Τρόπος 3: Σε περιβάλλον Jupyter Notebook ή Google Colab
Αν γράφετε τον κώδικα σε Notebook, πρέπει να χρησιμοποιήσετε την ειδική εντολή (cell magic) `%%manim` στην αρχή του κελιού, ώστε να εμφανιστεί το βίντεο απευθείας μέσα στο Notebook:

```python
%%manim -v WARNING -qp SimpleCircle

from manim import *

class SimpleCircle(Scene):
    def construct(self):
        circle = Circle(radius=1.5, color=RED)
        self.play(Create(circle))
        self.wait(1)
```

*(Σημείωση: Αν επιλέξετε τον Τρόπο 1 ή 2, βεβαιωθείτε ότι έχετε εγκαταστήσει σωστά τις εξωτερικές εξαρτήσεις της Manim στο σύστημά σας, όπως το FFmpeg, το οποίο είναι απαραίτητο για τη σύνθεση των αρχείων βίντεο).*
