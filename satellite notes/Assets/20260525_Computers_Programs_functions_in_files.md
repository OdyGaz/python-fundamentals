## Ερώτηση 2: Έχω μερικές συναρτήσεις στο αρχείο `example_2.py`. Πώς μπορώ να τις καλέσω από άλλο αρχείο;

Στην Python, η λέξη **`def`** είναι συντόμευση της αγγλικής λέξης **define** (δηλαδή «ορίζω» ή «ορισμός»). 

Χρησιμοποιείται για να δηλώσει στον διερμηνέα (interpreter) της Python ότι ξεκινάει ο **ορισμός μιας συνάρτησης**.

Υπάρχουν μερικοί βασικοί λόγοι για τους οποίους επιλέχθηκε αυτή η συγκεκριμένη λέξη:

1. **Συντομία και Αναγνωσιμότητα:** Ο δημιουργός της Python, Guido van Rossum, ήθελε η γλώσσα να είναι καθαρή και εύκολη στην ανάγνωση. Η λέξη `def` έχει μόνο 3 γράμματα, γεγονός που κάνει τον κώδικα πιο σύντομο σε σχέση με άλλες γλώσσες που χρησιμοποιούν ολόκληρη τη λέξη `function` (όπως η JavaScript) ή `procedure`.
2. **Ιστορική επιρροή:** Πολλές παλαιότερες προγραμματιστικές γλώσσες επηρέασαν τη σχεδίαση της Python. Για παράδειγμα, στη γλώσσα LISP χρησιμοποιείται το `defun` (define function) για τον ορισμό συναρτήσεων.
3. **Καθιέρωση προτύπου:** Με τη χρήση του `def`, διαχωρίζεται ξεκάθαρα η δημιουργία μιας συνάρτησης από άλλες ενέργειες (όπως η δημιουργία μιας κλάσης με τη λέξη `class` ή η ανάθεση τιμής σε μια μεταβλητή).


Έστω ότι στο αρχείο **`example_2.py`** έχετε την εξής συνάρτηση:
```python
# Αρχείο: example_2.py
def greet(name):
    print("Γεια σου,", name)
```

Μπορείτε να την καλέσετε από ένα άλλο αρχείο (π.χ. `main.py`) με 3 διαφορετικούς τρόπους:

### Τρόπος 1: Εισαγωγή όλου του αρχείου (Συνιστώμενος)
Εισάγετε το αρχείο και καλείτε τη συνάρτηση γράφοντας το όνομα του αρχείου και μια τελεία `.` μπροστά της.
```python
# Αρχείο: main.py
import example_2

example_2.greet("Γιάννη")
```
* *Πλεονέκτημα:* Είναι ο πιο ασφαλής τρόπος, γιατί ξέρετε ανά πάσα στιγμή από ποιο αρχείο προέρχεται η κάθε συνάρτηση.

### Τρόπος 2: Εισαγωγή συγκεκριμένης συνάρτησης
Εισάγετε απευθείας τη συνάρτηση, οπότε δεν χρειάζεται να γράφετε το `example_2.` μπροστά της.
```python
# Αρχείο: main.py
from example_2 import greet

greet("Μαρία")
```
* *Πλεονέκτημα:* Ο κώδικάς σας γίνεται πιο σύντομος και καθαρός.

### Τρόπος 3: Εισαγωγή με ψευδώνυμο (Alias)
Δίνετε ένα πιο σύντομο «παρατσούκλι» στο αρχείο εισαγωγής.
```python
# Αρχείο: main.py
import example_2 as ex2

ex2.greet("Ελένη")
```

> ⚠️ **Σημαντικό Tip:** Αν στο αρχείο `example_2.py` έχετε εντολές έξω από συναρτήσεις, αυτές θα εκτελεστούν αυτόματα κατά το `import`. Για να το αποφύγετε, τοποθετήστε τις εντολές δοκιμής μέσα στο παρακάτω μπλοκ στο τέλος του `example_2.py`:
> ```python
> if __name__ == "__main__":
>     greet("Δοκιμαστικό Όνομα") # Θα τρέξει μόνο αν εκτελέσετε απευθείας το example_2.py
> ```
