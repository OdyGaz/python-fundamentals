## Το λάθος στον κώδικα

Ο κώδικας:
```python
n=3
fact = 1; for i in range(2, n+1): fact *=i print(fact)
```

### Διάγνωση

Το λάθος είναι **συντακτικό (syntax error)**. Συγκεκριμένα, μετά την εντολή `fact *= i` λείπει ένας **ερώτημα (semicolon)** ή μια **αλλαγή γραμμής** πριν από το `print(fact)`.

#### Τι συμβαίνει:

- Η Python επιτρέπει πολλές εντολές στην ίδια γραμμή, χωρισμένες με `;`.
- Μέσα σε έναν βρόχο `for` που γράφεται σε μία γραμμή, το σώμα του βρόχου είναι μία μόνο εντολή (ή πολλές χωρισμένες με `;`).
- Εδώ, μετά την `fact *= i`, ο διερμηνέας συναντά το `print(fact)` χωρίς διαχωριστικό. Έτσι νομίζει ότι το `fact *= i print(fact)` είναι μια ενιαία, άγνωστη εντολή – και εμφανίζεται σφάλμα.

#### Το μήνυμα λάθους (ενδεικτικά):
```
SyntaxError: invalid syntax
```

### Σωστές εκδοχές

#### 1. Με ερωτηματικό (όλα στην ίδια γραμμή):
```python
n = 3
fact = 1; 
for i in range(2, n+1): fact *= i; print(fact)
```
(Το `print` εκτελείται κάθε φορά που ολοκληρώνεται η επανάληψη, οπότε θα τυπώσει 2, 6, ... Αν θέλουμε να τυπωθεί μόνο το τελικό αποτέλεσμα, το `print` πρέπει να είναι μετά τον βρόχο.)

#### 2. Κανονική μορφή (προτεινόμενη):
```python
n = 3
fact = 1
for i in range(2, n+1):
    fact *= i
print(fact)
```
(Το `print` είναι εκτός βρόχου, τυπώνει μία φορά το `6`.)

#### 3. Αν θέλουμε το `print` μέσα στον βρόχο (για εκτύπωση ενδιάμεσων τιμών):
```python
n = 3
fact = 1
for i in range(2, n+1):
    fact *= i
    print(fact)
```
(Θα τυπώσει `2` και μετά `6`.)

### Συμπέρασμα

**Λάθος:** Λείπει διαχωριστικό (`;` ή αλλαγή γραμμής) μεταξύ του `fact *= i` και του `print(fact)` μέσα στην ίδια γραμμή μετά το `for`.  
**Διόρθωση:** Χωρίστε τον κώδικα σε πολλαπλές γραμμές ή βάλτε `;` πριν το `print`.
