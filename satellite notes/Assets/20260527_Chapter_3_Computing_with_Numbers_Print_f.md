### 1. Η συνάρτηση `print()`
Είναι η βασική ενσωματωμένη συνάρτηση της Python που εμφανίζει το περιεχόμενο που βρίσκεται μέσα στις παρενθέσεις στην κονσόλα.

### 2. Το πρόθεμα `f` πριν από τα εισαγωγικά (`f"..."`)
Δηλώνει ότι χρησιμοποιείται ένα **f-string** (formatted string literal). Αυτή η δυνατότητα επιτρέπει την εύκολη ενσωμάτωση μεταβλητών ή εκφράσεων απευθείας μέσα σε ένα αλφαριθμητικό (string), τοποθετώντας τες μέσα σε άγκιστρα `{}`.

### 3. Το σταθερό κείμενο `Cost per square inch = $`
Αυτό είναι απλό κείμενο που θα εκτυπωθεί ακριβώς όπως αναγράφεται. Το σύμβολο του δολαρίου (`$`) βρίσκεται εκτός των αγκίστρων, επομένως θα εμφανιστεί ως χαρακτήρας ακριβώς πριν από την τιμή.

### 4. Το δυναμικό τμήμα `{cost_per_sq_inch:.4f}`
Αυτό το κομμάτι μέσα στα άγκιστρα αναλύεται ως εξής:
* **`cost_per_sq_inch`**: Είναι το όνομα της μεταβλητής της οποίας την τιμή θέλουμε να εμφανίσουμε.
* **`:` (άνω κάτω τελεία)**: Διαχωρίζει το όνομα της μεταβλητής από τις οδηγίες μορφοποίησής της.
* **`.4f`**: Είναι ο προσδιοριστής μορφοποίησης (format specifier):
  * Το **`.4`** ορίζει ότι ο αριθμός θα εμφανιστεί με ακριβώς **4 δεκαδικά ψηφία**.
  * Το **`f`** σημαίνει "fixed-point" και υποδηλώνει ότι η τιμή θα αντιμετωπιστεί και θα εμφανιστεί ως δεκαδικός αριθμός (float). Αν η τιμή έχει περισσότερα δεκαδικά ψηφία, γίνεται αυτόματη στρογγυλοποίηση.

---

### Παράδειγμα εφαρμογής

Αν στο πρόγραμμά σας ορίσετε τη μεταβλητή ως εξής:

```python
cost_per_sq_inch = 0.123456
print(f"Cost per square inch = ${cost_per_sq_inch:.4f}")
```

Το αποτέλεσμα που θα εμφανιστεί στην οθόνη είναι:
```text
Cost per square inch = $0.1235
```
*(Παρατηρήστε ότι το `0.123456` στρογγυλοποιήθηκε στα 4 δεκαδικά ψηφία, δηλαδή σε `0.1235`)*.

---

Στα f-strings της Python, μετά την άνω κάτω τελεία (`:`), μπορείτε να χρησιμοποιήσετε μια μεγάλη ποικιλία από **format specifiers** (προσδιοριστές μορφοποίησης) που ανήκουν στη γλώσσα μορφοποίησης της Python (Format Specification Mini-Language).

Ακολουθούν οι πιο συνηθισμένοι και χρήσιμοι προσδιοριστές, χωρισμένοι ανά κατηγορία:

---

### 1. Προσδιοριστές Τύπου (Type Specifiers)
Καθορίζουν πώς πρέπει να παρουσιαστεί η τιμή (ως ακέραιος, δεκαδικός, δυαδικός κ.λπ.):

* **`d` (Decimal Integer):** Για ακέραιους αριθμούς.
  ```python
  num = 42
  print(f"{num:d}")  # Έξοδος: "42"
  ```
* **`b` (Binary):** Μετατρέπει τον αριθμό σε δυαδικό σύστημα.
  ```python
  print(f"{num:b}")  # Έξοδος: "101010"
  ```
* **`x` / `X` (Hexadecimal):** Μετατρέπει τον αριθμό σε δεκαεξαδικό σύστημα (με πεζά ή κεφαλαία γράμματα αντίστοιχα).
  ```python
  print(f"{255:x}")  # Έξοδος: "ff"
  print(f"{255:X}")  # Έξοδος: "FF"
  ```
* **`e` / `E` (Scientific/Exponent):** Εμφανίζει τον αριθμό σε επιστημονική σημείωση.
  ```python
  print(f"{1000:.2e}")  # Έξοδος: "1.00e+03"
  ```
* **`%` (Percentage):** Πολλαπλασιάζει τον αριθμό με το 100, τον εμφανίζει ως δεκαδικό και προσθέτει το σύμβολο `%` στο τέλος.
  ```python
  rate = 0.75
  print(f"{rate:%}")     # Έξοδος: "75.000000%"
  print(f"{rate:.0%}")   # Έξοδος: "75%" (χωρίς δεκαδικά)
  ```

---

### 2. Διαχωριστικά Χιλιάδων (Thousands Separators)
Βοηθούν στην ανάγνωση μεγάλων αριθμών προσθέτοντας αυτόματα διαχωριστικά:

* **`,` (Κόμμα):** Χρησιμοποιεί το κόμμα ως διαχωριστικό χιλιάδων.
  ```python
  money = 1000000
  print(f"{money:,}")  # Έξοδος: "1,000,000"
  ```
* **`_` (Κάτω παύλα):** Χρησιμοποιεί την κάτω παύλα ως διαχωριστικό.
  ```python
  print(f"{money:_}")  # Έξοδος: "1_000_000"
  ```

---

### 3. Στοίχιση και Πλάτος (Alignment & Width)
Χρησιμοποιούνται κυρίως για τη δημιουργία στοιχισμένων στηλών ή πινάκων στην κονσόλα, ορίζοντας ένα ελάχιστο πλάτος χαρακτήρων:

* **`<` (Αριστερή στοίχιση):**
  ```python
  text = "test"
  print(f"{text:<10}")  # Έξοδος: "test      " (συνολικό μήκος 10 χαρακτήρες)
  ```
* **`>` (Δεξιά στοίχιση):**
  ```python
  print(f"{text:>10}")  # Έξοδος: "      test"
  ```
* **`^` (Στοίχιση στο κέντρο):**
  ```python
  print(f"{text:^10}")  # Έξοδος: "   test   "
  ```
* **Γέμισμα με χαρακτήρα:** Μπορείτε να ορίσετε έναν χαρακτήρα που θα γεμίσει το κενό διάστημα πριν από το σύμβολο στοίχισης.
  ```python
  print(f"{text:-^10}")  # Έξοδος: "---test---"
  ```

---

### 4. Διαχείριση Προσήμου (Sign)
Καθορίζει πώς θα εμφανίζονται τα πρόσημα `+` και `-`:

* **`+`:** Εμφανίζει πάντα το πρόσημο, είτε ο αριθμός είναι θετικός είτε αρνητικός.
  ```python
  pos = 5
  neg = -5
  print(f"{pos:+d} {neg:+d}")  # Έξοδος: "+5 -5"
  ```
* **` ` (κενό διάστημα):** Αφήνει ένα κενό διάστημα για τους θετικούς αριθμούς (ώστε να ευθυγραμμίζονται με τους αρνητικούς που έχουν το `-`).
  ```python
  print(f"{pos: d}")  # Έξοδος: " 5"
  print(f"{neg: d}")  # Έξοδος: "-5"
  ```

---

### 5. Μορφοποίηση Ημερομηνιών και Ώρας (Datetime Formatting)
Αν η μεταβλητή σας είναι αντικείμενο `datetime`, μπορείτε να χρησιμοποιήσετε τους κλασικούς προσδιοριστές ημερομηνίας απευθείας μέσα στο f-string:

```python
from datetime import datetime
now = datetime.now()

print(f"{now:%Y-%m-%d %H:%M:%S}") 
# Έξοδος π.χ.: "2026-05-28 14:30:15" (ανάλογα με την τρέχουσα ώρα)
```

### Συνδυασμός Προσδιοριστών
Μπορείτε να συνδυάσετε πολλούς προσδιοριστές μαζί. Η σειρά έχει σημασία (συνήθως ακολουθείται η σειρά: *στοίχιση/πλάτος -> διαχωριστικό -> ακρίβεια -> τύπος*).

**Παράδειγμα:**
Θέλουμε έναν αριθμό με δεξιά στοίχιση σε πλάτος 12 χαρακτήρων, με διαχωριστικό χιλιάδων και 2 δεκαδικά ψηφία:
```python
value = 12345.678
print(f"{value:>12,.2f}")  # Έξοδος: "   12,345.68"
```
