# README: Η μαγική γραμμή `if __name__ == "__main__"` στην Python

## Τι είναι αυτή η γραμμή και γιατί υπάρχει;

```python
if __name__ == "__main__":
    main()
```

Είναι ένας τρόπος να πούμε στην Python:

> «Εκτέλεσε αυτόν τον κώδικα ΜΟΝΟ αν το τρέχεις απευθείας, όχι αν κάποιος το εισάγει (import) από αλλού.»

## Το πρόβλημα που λύνει

### Χωρίς την `if` (λάθος τρόπος)

```python
# calculator.py
def add(a, b):
    return a + b

print("Καλωσήρθες στην αριθμομηχανή!")
result = add(5, 3)
print(f"5+3 = {result}")
```

Αν κάποιος άλλος γράψει:

```python
# main.py
import calculator   # Θα εκτυπωθούν τα μηνύματα!
x = calculator.add(10, 20)
```

Τα μηνύματα `"Καλωσήρθες..."` θα εμφανιστούν, παρόλο που ο χρήστης ήθελε απλά να χρησιμοποιήσει τη συνάρτηση `add`. Αυτό είναι ενοχλητικό και μη αναμενόμενο.

### Με την `if` (σωστός τρόπος)

```python
# calculator.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    print("Καλωσήρθες στην αριθμομηχανή!")
    result = add(5, 3)
    print(f"5+3 = {result}")
```

Τώρα:

- Αν τρέξεις `python calculator.py` → εκτυπώνονται τα μηνύματα.
- Αν κάνεις `import calculator` → **τίποτα** δεν εκτυπώνεται. Μόνο ορίζεται η `add`.

## Πώς δουλεύει;

Κάθε αρχείο Python έχει μια ειδική μεταβλητή που λέγεται `__name__`.

| Περίπτωση | Τιμή της `__name__` |
|-----------|---------------------|
| Το αρχείο εκτελείται απευθείας (`python myfile.py`) | `"__main__"` |
| Το αρχείο εισάγεται (`import myfile`) | `"myfile"` (το όνομα του αρχείου) |

Οπότε η συνθήκη `if __name__ == "__main__":` είναι αληθής **μόνο** όταν το αρχείο τρέχει ως κύριο πρόγραμμα.

## Το κλασικό μοτίβο

```python
def main():
    # όλος ο κώδικας του προγράμματος
    pass

if __name__ == "__main__":
    main()
```

## Πότε ΔΕΝ τη χρειάζεσαι

- Όταν γράφεις ένα μικρό script μίας χρήσης.
- Όταν το αρχείο προορίζεται αποκλειστικά για import (π.χ. βιβλιοθήκη συναρτήσεων) και **δεν έχεις βάλει καμία κλήση συναρτήσεων** στο κυρίως σώμα.
- Σε διαδραστικό περιβάλλον (Jupyter, REPL) – εκεί δεν έχει νόημα.

## Σύνοψη σε ένα παράδειγμα

```python
# demo.py
def say_hello():
    print("Γεια!")

print("__name__ =", __name__)

if __name__ == "__main__":
    print("Αυτό εκτελείται μόνο όταν τρέχω απευθείας.")
    say_hello()
```

**Τρέχοντας απευθείας:**
```
$ python demo.py
__name__ = __main__
Αυτό εκτελείται μόνο όταν τρέχω απευθείας.
Γεια!
```

**Κάνοντας import:**
```python
>>> import demo
__name__ = demo
>>> demo.say_hello()
Γεια!
```

## Τελικό συμπέρασμα

Χρησιμοποίησε `if __name__ == "__main__":` όταν θέλεις το αρχείο σου να είναι **ταυτόχρονα**:

- ένα εκτελέσιμο πρόγραμμα (τρέχοντας το απευθείας)
- μια βιβλιοθήκη (εισάγοντας το από αλλού)

Είναι σήμα κατατεθέν του καλού, επαγγελματικού κώδικα στην Python.


---

Αυτή η εντολή είναι ένα από τα πιο συνηθισμένα μοτίβα (patterns) στην Python. Χρησιμοποιείται για να ελέγξει **αν το αρχείο κώδικα εκτελείται απευθείας από εσάς** ή **αν έχει εισαχθεί (imported) ως βιβλιοθήκη σε κάποιο άλλο αρχείο**.

Ας δούμε αναλυτικά πώς λειτουργεί:

### 1. Τι είναι το `__name__` και το `"__main__"`;
* **`__name__`**: Είναι μια ειδική, ενσωματωμένη μεταβλητή που δημιουργεί αυτόματα η Python για κάθε αρχείο κώδικα (script) που εκτελείται. Η Python της δίνει αυτόματα μια τιμή (ένα string), ανάλογα με τον τρόπο που τρέχει το αρχείο.
* **`"__main__"`**: Είναι το όνομα που δίνει η Python στο περιβάλλον του αρχείου που εκτελείται ως το "κύριο" (main) πρόγραμμα.

### 2. Τα δύο σενάρια εκτέλεσης

#### Σενάριο Α: Εκτελείτε το αρχείο απευθείας
Αν ανοίξετε το τερματικό σας και γράψετε, για παράδειγμα, `python my_program.py`:
1. Η Python θα θέσει τη μεταβλητή `__name__` ίση με `"__main__"`.
2. Η συνθήκη `if __name__ == "__main__":` θα είναι **Αληθής (True)**.
3. Ο κώδικας μέσα στο `if` θα εκτελεστεί, δηλαδή θα καλεστεί η συνάρτηση `main()`.

#### Σενάριο Β: Εισάγετε το αρχείο σε κάποιο άλλο (Import)
Αν έχετε ένα δεύτερο αρχείο (π.χ. `another_program.py`) και μέσα σε αυτό γράψετε `import my_program`:
1. Η Python θα εκτελέσει το `my_program.py`, αλλά αυτή τη φορά θα θέσει τη μεταβλητή `__name__` ίση με το όνομα του αρχείου, δηλαδή `"my_program"`.
2. Η συνθήκη `if __name__ == "__main__":` θα είναι **Ψευδής (False)** (αφού `"my_program" != "__main__"`).
3. Ο κώδικας μέσα στο `if` **δεν θα εκτελεστεί**. Η συνάρτηση `main()` δεν θα καλεστεί αυτόματα.

---

### Γιατί είναι χρήσιμο αυτό;

Αυτό το μοτίβο σάς επιτρέπει να γράφετε κώδικα που είναι διπλής χρήσης:
1. **Ως αυτόνομο πρόγραμμα:** Μπορείτε να το τρέξετε απευθείας για να εκτελέσει μια συγκεκριμένη εργασία (μέσω της `main()`).
2. **Ως βιβλιοθήκη (module):** Μπορείτε να εισάγετε τις συναρτήσεις ή τις κλάσεις του αρχείου σε άλλα προγράμματα, χωρίς να εκτελείται αυτόματα ολόκληρο το πρόγραμμα ή τα τεστ που έχετε γράψει για αυτό.

### Παράδειγμα

Έστω ότι έχετε το αρχείο `math_tools.py`:

```python
def double(x):
    return x * 2

def main():
    print("Εκτέλεση δοκιμών για το math_tools:")
    print(f"Το διπλάσιο του 5 είναι: {double(5)}")

if __name__ == "__main__":
    main()
```

* Αν τρέξετε το `math_tools.py` απευθείας, θα δείτε στην οθόνη τα μηνύματα δοκιμής από τη συνάρτηση `main()`.
* Αν σε ένα άλλο αρχείο γράψετε `from math_tools import double`, μπορείτε να χρησιμοποιήσετε τη συνάρτηση `double()` ελεύθερα, χωρίς να εμφανιστούν στην οθόνη σας τα μηνύματα δοκιμής της `main()`.
