# example

```python
from manim import *

class MyFirstScene(Scene):
    def construct(self):
        # 1. Δημιουργούμε τον κύκλο με βάση τις παραμέτρους του πίνακα
        my_circle = Circle(radius=1.0, color=RED, fill_opacity=0.5)
        
        # 2. Δημιουργούμε το τετράγωνο με βάση τις παραμέτρους του πίνακα
        my_square = Square(side_length=2.0, color=BLUE)
        
        # 3. Τοποθετούμε το τετράγωνο στα δεξιά του κύκλου
        my_square.next_to(my_circle, RIGHT)
        
        # 4. Δίνουμε εντολή να εμφανιστούν στην οθόνη με animation
        self.play(Create(my_circle))
        self.play(Create(my_square))
        self.wait(1)
```

### 1. Η `class` (Κλάση)
```python
class MyFirstScene(Scene):
```
* **Τι κάνει η `class`:** Στην Python, η λέξη `class` χρησιμοποιείται για να ορίσουμε μια νέα κατηγορία πραγμάτων (ένα "καλούπι"). 
* **Γιατί γράφουμε `(Scene)`:** Το `Scene` είναι ένα έτοιμο αντικείμενο που έχει φτιάξει η Manim. Έχει ήδη μέσα του όλο τον δύσκολο κώδικα για το πώς λειτουργεί η κάμερα, πώς γίνεται η επεξεργασία του βίντεο, πώς αποθηκεύεται το αρχείο κ.λπ. 
* **Στην πράξη:** Γράφοντας αυτή τη γραμμή, λέτε στη Manim: *«Θέλω να φτιάξω μια δική μου σκηνή (με όνομα `MyFirstScene`) η οποία θα δανειστεί και θα χρησιμοποιήσει όλα τα έτοιμα εργαλεία της `Scene`»*.

---

### 2. Το `def` (Function/Method)
```python
    def construct(self):
```
* **Τι κάνει το `def`:** Η λέξη `def` (από το *define*) χρησιμοποιείται για να ορίσουμε μια **ενέργεια** (μια συνάρτηση).
* **Γιατί ονομάζεται `construct`;** Το `construct` (που σημαίνει "κατασκεύασε") είναι ένα ειδικό όνομα που περιμένει η Manim να βρει μέσα στον κώδικα. Όταν τρέχετε το πρόγραμμα, η Manim ψάχνει αυτόματα να βρει τη λέξη `construct` για να ξεκινήσει να σχεδιάζει.
* **Στην πράξη:** Μέσα σε αυτό το `def`, γράφετε βήμα-βήμα τι ακριβώς θα συμβεί στο βίντεο (ποια σχήματα θα δημιουργηθούν, πώς θα κινηθούν και πότε θα σταματήσουν).

---

### Τι σημαίνει το `self` μέσα στην παρένθεση;
Το `self` σημαίνει «ο εαυτός μου». Λέει στον κώδικα ότι οι ενέργειες που γράφουμε (όπως το `self.play(...)`) θα εκτελεστούν πάνω σε αυτήν ακριβώς τη σκηνή που δημιουργούμε εκείνη τη στιγμή.


---
### 1. Για το `class MyFirstScene(Scene):`
* **Μπορείτε να ονομάσετε το `MyFirstScene` όπως θέλετε;**
  **Ναι, απολύτως.** Είναι απλώς ένα όνομα που επιλέγετε εσείς. Μπορείτε να το ονομάσετε `MyAnimation`, `Intro`, `Scene1`, `LessonA` ή οτιδήποτε άλλο (αρκεί να ξεκινάει με γράμμα και να μην έχει κενά).
* **Είναι υποχρεωτικό το `Scene` στην παρένθεση;**
  **Ναι, είναι υποχρεωτικό.** Με αυτόν τον τρόπο λέτε στην Python ότι η δική σας κλάση (π.χ. η `MyFirstScene`) θα κληρονομήσει όλες τις ιδιότητες και τα εργαλεία της έτοιμης κλάσης `Scene` της Manim. (Υπάρχουν και άλλες εξειδικευμένες κλάσεις στην πορεία, όπως η `ThreeDScene` για τρισδιάστατα γραφικά, αλλά όλες βασίζονται στη `Scene`).

---

### 2. Για το όνομα `construct`
* **Μπορεί να έχει άλλο όνομα;**
  **Όχι, δεν μπορεί.** Πρέπει να ονομάζεται υποχρεωτικά και ακριβώς `construct`. Η Manim είναι προγραμματισμένη έτσι ώστε, όταν ξεκινάει να δημιουργήσει το βίντεο, να ψάχνει μέσα στην κλάση σας μια συνάρτηση με το όνομα `construct`. Αν την ονομάσετε κάπως αλλιώς (π.χ. `my_code`), η Manim θα εμφανίσει σφάλμα (error) επειδή δεν θα ξέρει από ποιο σημείο να ξεκινήσει τη σχεδίαση.

---

### 3. Για το όρισμα `self`
Το `self` είναι ένας βασικός κανόνας της γλώσσας Python όταν δουλεύουμε με κλάσεις. 
* Σκεφτείτε το `self` σαν την αντωνυμία **«εαυτός μου»** ή **«εγώ»**.
* Όταν ορίζουμε μια συνάρτηση μέσα σε μια κλάση (όπως η `construct`), η Python απαιτεί να βάζουμε το `self` ως πρώτο όρισμα στην παρένθεση. 
* Με αυτόν τον τρόπο, η συνάρτηση `construct` ξέρει ότι οι εντολές που θα εκτελέσει (π.χ. να προσθέσει έναν κύκλο) θα εφαρμοστούν πάνω **στη συγκεκριμένη σκηνή** που τρέχει εκείνη τη στιγμή. 

---

### 4. Από πού αντλείται το `play` στο `self.play(...)`;
Το `play` αντλείται απευθείας από την κλάση **`Scene`** που βάλατε στην παρένθεση της πρώτης γραμμής.
Οι δημιουργοί της Manim έχουν γράψει έτοιμο κώδικα για εσάς. Μέσα στην κλάση `Scene`, έχουν ορίσει μια συνάρτηση που λέγεται `play` και η οποία αναλαμβάνει να πάρει ένα σχήμα και να το εμφανίσει στην οθόνη με κίνηση.
Επειδή εσείς γράψατε `class MyFirstScene(Scene):`, η κλάση σας **κληρονόμησε** (πήρε αυτόματα) όλες τις έτοιμες λειτουργίες της `Scene`. 

Έτσι, γράφοντας:
```python
self.play(...)
```
Στην πραγματικότητα λέτε στον κώδικα: *«Εαυτέ μου (`self`), χρησιμοποίησε την έτοιμη λειτουργία `play` που κληρονομήσαμε από τη `Scene` για να δείξεις αυτό το animation»*.


---

Για να καταλάβουμε γιατί δεν γράφουμε `Scene.play()` ή `MyFirstScene.play()`, πρέπει να δούμε τη διαφορά ανάμεσα στο **σχέδιο (κλάση)** και στο **πραγματικό αντικείμενο (instance)**.

---

### Η παρομοίωση με το Αυτοκίνητο

Φανταστείτε ότι η κλάση `Scene` είναι το **αρχιτεκτονικό σχέδιο ενός αυτοκινήτου** (στο χαρτί). 
Το σχέδιο αυτό περιγράφει ότι το αυτοκίνητο έχει μια λειτουργία που λέγεται `drive()` (οδήγηση).

* Αν γράψετε `Scene.drive()`, είναι σαν να πηγαίνετε στο σχέδιο πάνω στο χαρτί και να του λέτε «ξεκίνα να οδηγείς». Το σχέδιο στο χαρτί δεν μπορεί να οδηγήσει, γιατί δεν είναι πραγματικό αυτοκίνητο.
* Για να οδηγήσετε, πρέπει πρώτα το εργοστάσιο να πάρει το σχέδιο και να κατασκευάσει ένα **πραγματικό, φυσικό αυτοκίνητο** (αυτό στον προγραμματισμό το λέμε *αντικείμενο* ή *instance*). 
* Μόνο πάνω σε αυτό το πραγματικό αυτοκίνητο μπορείτε να καλέσετε τη λειτουργία οδήγησης.

---

### Γιατί όχι `Scene.play()` ή `MyFirstScene.play()`;

Τόσο το `Scene` όσο και το `MyFirstScene` είναι **κλάσεις (σχέδια στο χαρτί)**. 
Αν γράφαμε `Scene.play()` ή `MyFirstScene.play()`, η Python θα μπερδευόταν γιατί θα προσπαθούσαμε να εκτελέσουμε μια ενέργεια πάνω στο γενικό σχέδιο και όχι σε μια συγκεκριμένη, ζωντανή σκηνή που τρέχει εκείνη τη στιγμή στη μνήμη του υπολογιστή.

---

### Τι κάνει τελικά το `self.play()`;

Όταν εσείς πατάτε να τρέξει το πρόγραμμα της Manim, η βιβλιοθήκη κάνει κρυφά στο παρασκήνιο τα εξής βήματα:

1. Παίρνει το σχέδιο `MyFirstScene` και κατασκευάζει ένα **πραγματικό, ζωντανό αντικείμενο σκηνής** στη μνήμη του υπολογιστή (ας πούμε ότι το ονομάζει εσωτερικά `trehousa_skini`).
2. Στη συνέχεια, καλεί το σενάριο: `trehousa_skini.construct()`.
3. Όταν εκτελείται η `construct`, η Python αντικαθιστά αυτόματα τη λέξη `self` με το πραγματικό αντικείμενο (`trehousa_skini`). 
4. Έτσι, το `self.play()` μεταφράζεται αυτόματα σε `trehousa_skini.play()`.

**Με απλά λόγια:**
Επειδή όταν γράφουμε τον κώδικα δεν ξέρουμε πώς θα ονομάσει η Manim το πραγματικό αντικείμενο της σκηνής που θα δημιουργήσει στο μέλλον,
χρησιμοποιούμε τη λέξη **`self`** (που σημαίνει «ο εαυτός μου») ως έναν προσωρινό κωδικό που αντιπροσωπεύει τη συγκεκριμένη,
ζωντανή σκηνή που θα δημιουργηθεί όταν τρέξει το πρόγραμμα.
