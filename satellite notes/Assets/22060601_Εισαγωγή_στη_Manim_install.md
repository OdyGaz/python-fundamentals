# Οδηγός Εγκατάστασης Manim (Community Edition)

Το παρόν έγγραφο περιγράφει βήμα προς βήμα τη διαδικασία εγκατάστασης της βιβλιοθήκης **Manim** και των απαραίτητων συστημικών εξαρτήσεων (dependencies) για την παραγωγή βίντεο και μαθηματικών γραφικών.

---

## 1. Απαραίτητες Εξαρτήσεις (Prerequisites)
Για να λειτουργήσει πλήρως η Manim, το σύστημά σας χρειάζεται:
1. **Python 3.8+**: Η γλώσσα προγραμματισμού.
2. **FFmpeg**: Εργαλείο επεξεργασίας βίντεο και ήχου (απαραίτητο για τη σύνθεση των αρχείων `.mp4`).
3. **LaTeX (Προαιρετικό αλλά συνιστώμενο)**: Απαραίτητο για τη σύνταξη και απόδοση περίπλοκων μαθηματικών εξισώσεων και συμβόλων.
4. **Cairo & Pkg-config**: Βιβλιοθήκες γραφικών (κυρίως για macOS και Linux).

---

## 2. Οδηγίες Ανά Λειτουργικό Σύστημα

### Α. Windows
Ακολουθήστε τη σειρά των βημάτων για να ρυθμίσετε το περιβάλλον σας στα Windows 10/11.

#### Βήμα 1: Εγκατάσταση Python
* Κατεβάστε και εγκαταστήστε την τελευταία έκδοση της Python από το [python.org](https://www.python.org/).
* **Σημαντικό:** Κατά την εγκατάσταση, επιλέξτε το κουτάκι **"Add Python to PATH"**.

#### Βήμα 2: Εγκατάσταση FFmpeg
1. Κατεβάστε την έκδοση Windows του FFmpeg (π.χ. από το gyan.dev ή μέσω ενός package manager).
2. Αν χρησιμοποιείτε τον package manager **Chocolatey** ή **Scoop**, εκτελέστε στο PowerShell (ως διαχειριστής):
   ```powershell
   choco install ffmpeg
   ```
   ή
   ```
   scoop install ffmpeg
   ```
3. Αν το εγκαταστήσετε χειροκίνητα, βεβαιωθείτε ότι έχετε προσθέσει τη διαδρομή του φακέλου `bin` του FFmpeg στις μεταβλητές περιβάλλοντος του συστήματος (System PATH).

#### Βήμα 3: Εγκατάσταση LaTeX (MiKTeX)
* Κατεβάστε και εγκαταστήστε το **MiKTeX** από το [miktex.org](https://miktex.org/download).
* Κατά την εγκατάσταση, επιλέξτε την αυτόματη εγκατάσταση πακέτων (On-the-fly package installation: *Yes*).

#### Βήμα 4: Εγκατάσταση Manim
Ανοίξτε τη γραμμή εντολών (CMD) ή το PowerShell και πληκτρολογήστε:
```bash
pip install manim
```

---

### Β. macOS
Στο macOS, η εγκατάσταση γίνεται πολύ εύκολα χρησιμοποιώντας τον διαχειριστή πακέτων **Homebrew**.

#### Βήμα 1: Εγκατάσταση Εξαρτήσεων μέσω Homebrew
Ανοίξτε το Τερματικό (Terminal) και εκτελέστε την παρακάτω εντολή:
```bash
brew install py3cairo ffmpeg pkg-config
```

#### Βήμα 2: Εγκατάσταση LaTeX (Προαιρετικό)
Για την υποστήριξη μαθηματικών κειμένων, εγκαταστήστε το MacTeX:
```bash
brew install --cask mactex-no-gui
```

#### Βήμα 3: Εγκατάσταση Manim
Εκτελέστε στο Τερματικό:
```bash
pip3 install manim
```

#### Βήμα 2: Εγκατάσταση Manim
Συνιστάται η εγκατάσταση σε ένα εικονικό περιβάλλον (virtual environment) ή απευθείας μέσω pip:
```bash
pip3 install manim
```

## 4. Έλεγχος Επιτυχούς Εγκατάστασης
Για να επιβεβαιώσετε ότι όλα έχουν εγκατασταθεί σωστά, δημιουργήστε ένα αρχείο με το όνομα `test.py` και προσθέστε τον ακόλουθο κώδικα:

```python
from manim import *

class TestScene(Scene):
    def construct(self):
        # Έλεγχος βασικών σχημάτων
        square = Square(color=BLUE)
        self.play(Create(square))
        self.wait(1)
        
        # Έλεγχος LaTeX (αν έχει εγκατασταθεί)
        formula = MathTex(r"e^{i\pi} + 1 = 0")
        formula.next_to(square, DOWN)
        self.play(Write(formula))
        self.wait(1)
```

Εκτελέστε την εντολή στο τερματικό σας:
```bash
manim -pql test.py TestScene
```

*Αν ανοίξει ένα παράθυρο αναπαραγωγής που δείχνει ένα μπλε τετράγωνο και τη μαθηματική εξίσωση του Euler, η εγκατάστασή σας έχει ολοκληρωθεί με επιτυχία.*

## 5. Αντιμετώπιση Προβλημάτων (Troubleshooting)

* **Σφάλμα: `Command 'ffmpeg' not found`**  
  *Αιτία:* Το FFmpeg δεν έχει εγκατασταθεί ή η διαδρομή του δεν έχει προστεθεί στο PATH της συσκευής σας. Βεβαιωθείτε ότι η εντολή `ffmpeg -version` λειτουργεί στο τερματικό σας πριν τρέξετε τη Manim.
* **Σφάλμα: `Latex error converting to dvi` ή προβλήματα με το `MathTex`**  
  *Αιτία:* Το σύστημα LaTeX είτε λείπει είτε δεν είναι προσβάσιμο από τη Manim. Επανεκκινήστε το τερματικό ή τον υπολογιστή σας μετά την εγκατάσταση του LaTeX ώστε να ανανεωθούν οι διαδρομές συστήματος (PATH).
