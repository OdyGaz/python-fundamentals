
## Ερώτηση 3: Τι κάνει η εντολή `eval` στο: `x = eval(input("Enter a number between 0 and 1: "))`;

Η εντολή **`eval()`** (από το *evaluate*) παίρνει μια συμβολοσειρά (string) και **την εκτελεί σαν να ήταν πραγματικός κώδικας Python**.

### Πώς λειτουργεί στο συγκεκριμένο παράδειγμα;
1. **Το `input(...)` λαμβάνει την είσοδο ως κείμενο:** Αν ο χρήστης πληκτρολογήσει `.25`, η `input` επιστρέφει το string `".25"`.
2. **Το `eval(...)` εκτελεί το κείμενο:** Η `eval` παίρνει το string `".25"`, το αξιολογεί ως κώδικα και επιστρέφει τον πραγματικό δεκαδικό αριθμό `0.25` (τύπου float), αποθηκεύοντάς τον στη μεταβλητή `x` .

Αν ο χρήστης γράψει μια μαθηματική πράξη, όπως `1/4`, η `eval` θα την υπολογίσει και θα επιστρέψει το αποτέλεσμα (`0.25`).

### Γιατί χρησιμοποιούνταν παλαιότερα;
Σε παλαιότερα βιβλία, χρησιμοποιούνταν ως σύντομος τρόπος για να δέχεται το πρόγραμμα αριθμούς από τον χρήστη, χωρίς να χρειάζεται να εξηγηθεί άμεσα η διαφορά ανάμεσα σε ακέραιους (`int`) και δεκαδικούς (`float`).

### ⚠️ Ο Μεγάλος Κίνδυνος (Γιατί πρέπει να αποφεύγεται)
Η `eval` θεωρείται **εξαιρετικά επικίνδυνη για την ασφάλεια των συστημάτων**. Επειδή εκτελεί οποιονδήποτε κώδικα της δοθεί, ένας κακόβουλος χρήστης μπορεί να πληκτρολογήσει εντολές που θα καταστρέψουν ή θα παραβιάσουν το σύστημα.
Για παράδειγμα, αν ο χρήστης πληκτρολογήσει:
```python
__import__('os').system('rm -rf *') # Εντολή διαγραφής αρχείων
```
Η `eval` θα την εκτελέσει κανονικά, διαγράφοντας αρχεία του συστήματος.

### Η Ασφαλής Εναλλακτική Λύση
Πρέπει πάντα να μετατρέπετε την είσοδο (input) στον συγκεκριμένο τύπο δεδομένων που περιμένετε, χρησιμοποιώντας τις κατάλληλες συναρτήσεις:
* Για **δεκαδικούς αριθμούς**:
  ```python
  x = float(input("Enter a number between 0 and 1: "))
  ```
* Για **ακέραιους αριθμούς**:
  ```python
  x = int(input("Enter an integer: "))
  ```
