## 1. Συνοπτική Θεωρία (Brief Theory)
 
- **Τύποι δεδομένων (data types)**: Καθορίζουν ποιες τιμές μπορεί να πάρει ένα αντικείμενο και ποιες πράξεις επιτρέπονται.
- **Ακέραιοι (int)**: Αριθμοί χωρίς δεκαδικό μέρος. Π.χ., `5`, `-3`, `0`.
- **Κινητής υποδιαστολής (float)**: Αριθμοί με δεκαδικό μέρος ή σε εκθετική μορφή. Π.χ., `3.14`, `-0.001`, `2.5e3`.  
  **Σημείωση**: Οι `float` είναι προσεγγίσεις πραγματικών αριθμών (πεπερασμένη ακρίβεια).

### Βασικές πράξεις

| Τελεστής | Περιγραφή | Παράδειγμα (`int`) | Αποτέλεσμα |
|----------|-----------|---------------------|-------------|
| `+` | Πρόσθεση | `3 + 4` | `7` |
| `-` | Αφαίρεση | `10 - 7` | `3` |
| `*` | Πολλαπλασιασμός | `6 * 7` | `42` |
| `/` | Διαίρεση (πάντα `float`) | `10 / 3` | `3.333...` |
| `//` | Ακέραια διαίρεση (στρογγυλοποίηση προς τα κάτω) | `10 // 3` | `3` |
| `%` | Υπόλοιπο (modulo) | `10 % 3` | `1` |
| `**` | Ύψωση σε δύναμη | `2 ** 3` | `8` |
| `abs(x)` | Απόλυτη τιμή | `abs(-5)` | `5` |

- **Μικτές εκφράσεις**: Αν υπάρχει `float`, η Python μετατρέπει αυτόματα τους `int` σε `float` και το αποτέλεσμα είναι `float`.
- **Μετατροπή τύπου**:
  - `int(x)` – μετατρέπει σε `int` (αποκόπτει δεκαδικό μέρος).
  - `float(x)` – μετατρέπει σε `float`.
  - `round(x, n)` – στρογγυλοποίηση σε `n` δεκαδικά (επιστρέφει `int` αν `n` παραλειφθεί).
  - **Ασφαλής εισαγωγή**: Αντί για `eval(input())`, χρησιμοποιούμε `int(input())` ή `float(input())`.

**Εκφώνηση**: Υπολογίστε την τιμή και τον τύπο (int/float) των παρακάτω εκφράσεων Python:  
(α) `3 + 5`

(γ) `10 / 2`

- (ε) `7 % 3 = 1` → **int**
- (στ) `2 ** 0.5 = 1.4142135623730951` → **float** (δύναμη με float εκθέτη)

### Πρόβλημα 2 – Ακέραια διαίρεση και υπόλοιπο με αρνητικούς αριθμούς

**Εκφώνηση**: Χρησιμοποιώντας τον τύπο $a = (a // b) \cdot b + (a \% b)$, υπολογίστε (χωρίς υπολογιστή) και επαληθεύστε:
(α) `-10 // 3` και `-10 % 3`  
(β) `10 // -3` και `10 % -3`  
(γ) `-10 // -3` και `-10 % -3`

**Λύση**:

- (α) Για `a = -10, b = 3`:  
  Έστω `q = -10 // 3` και `r = -10 % 3`. Πρέπει $-10 = q \cdot 3 + r$ με $0 \le r < 3$.  
  Δοκιμάζοντας `q = -4`: $-4 \cdot 3 = -12$, τότε $r = (-10) - (-12) = 2$ (έγκυρο, $0 \le 2 < 3$).  
  Άρα `-10 // 3 = -4`, `-10 % 3 = 2`.

- (β) `a = 10, b = -3`:  
  $10 = q \cdot (-3) + r$, $0 \le r < |b| = 3$.  
  `q = -3` → $(-3)\cdot(-3)=9$, $r=10-9=1$.  
  Άρα `10 // -3 = -4`? Προσοχή: η Python θέλει το πηλίκο να στρογγυλοποιείται προς τα κάτω (floor).  
  Ας κάνουμε έλεγχο: `-4 * (-3) = 12`, $r = 10-12 = -2$ (μη αποδεκτό, r αρνητικό).  
  Σωστό `q = -4` δίνει r=-2. `q = -3` δίνει r=1 (σωστό).  
  Επαλήθευση: `-3 * (-3) = 9`, $r=1$. Πρέπει $0\le 1<3$, ισχύει.  
  Άρα `10 // -3 = -4`; Δεν ταιριάζει. Ας θυμηθούμε: Στην Python, η ακέραια διαίρεση `//` δίνει **floor division** (στρογγυλοποίηση προς τα κάτω στο ακέραιο).  
  Για 10 / -3 = -3.333..., floor = -4. Άρα `10 // -3 = -4`. Τότε $r = 10 - (-4)*(-3) = 10 - 12 = -2$.  
  Αλλά το υπόλοιπο `%` στην Python ικανοποιεί $a = (a//b)*b + (a\%b)$ και το υπόλοιπο έχει το **πρόσημο του διαιρέτη** (b). Δηλαδή $0 \le r < |b|$ **δεν ισχύει πάντα** όταν ο διαιρέτης είναι αρνητικός!  
  Στην Python, το υπόλοιπο παίρνει το πρόσημο του διαιρέτη. Οπότε για b=-3, το r έχει πρόσημο -.  
  Εφαρμόζοντας τον ορισμό: `10 // -3 = -4`, τότε `10 % -3 = 10 - (-4)*(-3) = 10 - 12 = -2`.  
  Ελέγξτε: `-4 * (-3) + (-2) = 12 - 2 = 10`. Σωστά.  
  Άρα `10 // -3 = -4`, `10 % -3 = -2`.

- (γ) `a = -10, b = -3`:  
  `-10 / -3 = 3.333...`, floor = 3.  
  `-10 // -3 = 3`.  
  `-10 % -3 = -10 - 3*(-3) = -10 + 9 = -1`.  
  Επαλήθευση: $3 \cdot (-3) + (-1) = -9 -1 = -10$.

### Πρόβλημα 4 – Τετραγωνική εξίσωση με βιβλιοθήκη math

**Εκφώνηση**: Γράψτε πρόγραμμα που υπολογίζει τις πραγματικές ρίζες μιας δευτεροβάθμιας εξίσωσης $ax^2+bx+c=0$, με χρήση της `math.sqrt()`. Προειδοποιήστε τον χρήστη αν η διακρίνουσα είναι αρνητική.

**Λύση**:

```python
import math

def main():
    print("Quadratic equation solver (real roots only)")
    a = float(input("a: "))
    b = float(input("b: "))
    c = float(input("c: "))
    d = b*b - 4*a*c
    if d < 0:
        print("No real roots (discriminant negative).")
    else:
        sqrt_d = math.sqrt(d)
        x1 = (-b + sqrt_d) / (2*a)
        x2 = (-b - sqrt_d) / (2*a)
        print(f"Roots: {x1} and {x2}")

if __name__ == "__main__":
    main()
```

**Εξήγηση**:  
- Η `math.sqrt()` απαιτεί μη αρνητικό όρισμα. Ελέγχουμε πρώτα τη διακρίνουσα.

### Πρόβλημα 5 – Παραγοντικό με συσσώρευση

**Εκφώνηση**: Υλοποιήστε πρόγραμμα που υπολογίζει το $n! = n \cdot (n-1) \cdots 1$, χρησιμοποιώντας βρόχο `for` και μεταβλητή συσσώρευσης. Δώστε αποτέλεσμα για $n=20$.

**Λύση**:

```python
def factorial(n):
    fact = 1
    for i in range(2, n+1):
        fact *= i
    return fact

def main():
    n = int(input("n: "))
    print(f"{n}! = {factorial(n)}")

if __name__ == "__main__":
    main()
```

**Δειγματική έξοδος** (n=20):  
`20! = 2432902008176640000`

**Εξήγηση**:  
- Αρχικοποίηση `fact = 1` (ουδέτερο στοιχείο πολλαπλασιασμού).  
- Ο βρόχος `range(2, n+1)` δίνει τους παράγοντες από 2 έως n.  
- Ο ακέραιος της Python μπορεί να αποθηκεύσει το τεράστιο αποτέλεσμα (20! ≈ 2.4×10¹⁸).

### Πρόβλημα 10 – Νιος αριθμός Fibonacci

**Εκφώνηση**: Η ακολουθία Fibonacci ορίζεται ως $F_1 = 1, F_2 = 1, F_n = F_{n-1} + F_{n-2}$ για $n \ge 3$. Υλοποιήστε πρόγραμμα που διαβάζει $n$ και υπολογίζει τον $n$-οστό όρο χρησιμοποιώντας βρόχο συσσώρευσης (χωρίς αναδρομή).

**Λύση**:

```python
def fibonacci(n):
    if n <= 0:
        return 0
    elif n == 1:
        return 1
    a, b = 1, 1
    for _ in range(3, n+1):
        a, b = b, a + b
    return b

def main():
    n = int(input("Enter n: "))
    print(f"F_{n} = {fibonacci(n)}")

if __name__ == "__main__":
    main()
```

**Εξήγηση**:  
- Μεταβλητές `a` (F_{k-2}) και `b` (F_{k-1}) αρχικοποιούνται στο 1,1 για n=2.  
- Για n=1 επιστρέφουμε 1.  
- Για n≥3, επαναλαμβάνουμε n-2 φορές: νέο a = b, νέο b = a_old + b_old.  
- Αποτέλεσμα για n=6: `8`.

1. **Μέσος όρος σειράς αριθμών**  
   Γράψτε πρόγραμμα που πρώτα διαβάζει έναν ακέραιο $N$ (πλήθος αριθμών) και στη συνέχεια διαβάζει $N$ πραγματικούς αριθμούς. Υπολογίστε και εκτυπώστε τον μέσο όρο (float).  
   *(Απάντηση: τρέξτε το πρόγραμμα με δικά σας δεδομένα. Π.χ., για N=3, αριθμοί 4, 5, 6 → μέσος όρος 5.0)*

```python
def main():
    # 1. Διάβασμα του πλήθους των αριθμών (N) από τον χρήστη
    n = int(input("Δώστε το πλήθος των αριθμών (N): "))
    
    # Έλεγχος σε περίπτωση που ο χρήστης δώσει μηδέν ή αρνητικό αριθμό
    if n <= 0:
        print("Το πλήθος πρέπει να είναι μεγαλύτερο από το μηδέν.")
        return

    total_sum = 0.0  # Μεταβλητή για την αποθήκευση του αθροίσματος

    # 2. Επανάληψη για να διαβάσουμε N πραγματικούς αριθμούς
    for i in range(n):
        num = float(input(f"Δώστε τον {i+1}ο αριθμό: "))
        total_sum += num  # Προσθέτουμε τον αριθμό στο συνολικό άθροισμα

    # 3. Υπολογισμός του μέσου όρου
    average = total_sum / n

    # 4. Εκτύπωση του μέσου όρου ως float (με 1 δεκαδικό ψηφίο)
    print(f"Μέσος όρος = {average:.1f}")


if __name__ == "__main__":
    main()
```


2. **Προσέγγιση του π**  
   Υλοποιήστε το άθροισμα $\pi \approx 4 - \frac{4}{3} + \frac{4}{5} - \frac{4}{7} + \cdots$ για $n$ όρους. Για $n=100000$, υπολογίστε την απόλυτη διαφορά από το `math.pi`.  
   *(Απάντηση: για 100.000 όρους το σφάλμα είναι περίπου $10^{-5}$)*

```python
import math

def calculate_leibniz_pi(n):
    pi_approx = 0.0
    sign = 1.0
    
    # Υλοποίηση του αθροίσματος: 4/1 - 4/3 + 4/5 - 4/7 + ...
    for i in range(n):
        term = sign * 4.0 / (2 * i + 1)
        pi_approx += term
        sign = -sign  # Εναλλαγή προσήμου για τον επόμενο όρο
        
    return pi_approx

def main():
    n = 100000
    
    # 1. Υπολογισμός της προσέγγισης με τη μέθοδο Leibniz
    approx_pi = calculate_leibniz_pi(n)
    
    # 2. Λήψη της ακριβούς τιμής από το math module της Python
    actual_pi = math.pi
    
    # 3. Υπολογισμός της απόλυτης διαφοράς
    absolute_difference = abs(approx_pi - actual_pi)
    
    # Εκτύπωση των αποτελεσμάτων
    print(f"Για n = {n:,} όρους:")
    print(f"Προσέγγιση Leibniz: {approx_pi:.15f}")
    print(f"Τιμή math.pi:       {actual_pi:.15f}")
    print(f"Απόλυτη διαφορά:    {absolute_difference:.15f}")

if __name__ == "__main__":
    main()
```


3. **Κλίση ευθείας**  
   Διαβάστε τέσσερις πραγματικούς αριθμούς $x_1, y_1, x_2, y_2$ και υπολογίστε την κλίση $\frac{y_2-y_1}{x_2-x_1}$, με έλεγχο για κάθετη ευθεία (διαίρεση με μηδέν).  
   *(Απάντηση: για $x_1=1, y_1=2, x_2=4, y_2=8$ → κλίση 2.0)*

```python
def main():
    print("Υπολογισμός Κλίσης Ευθείας")
    print("---------------------------")
    
    try:
        # 1. Εισαγωγή των συντεταγμένων από τον χρήστη
        x1 = float(input("Δώστε το x1: "))
        y1 = float(input("Δώστε το y1: "))
        x2 = float(input("Δώστε το x2: "))
        y2 = float(input("Δώστε το y2: "))
    except ValueError:
        print("Σφάλμα: Παρακαλώ εισάγετε έγκυρους πραγματικούς αριθμούς.")
        return

    # 2. Έλεγχος για ειδικές περιπτώσεις
    if x1 == x2:
        if y1 == y2:
            # Αν τα σημεία ταυτίζονται, δεν ορίζεται ευθεία
            print("\nΣφάλμα: Τα σημεία (x1, y1) και (x2, y2) συμπίπτουν. Δεν ορίζεται μοναδική ευθεία.")
        else:
            # Αν x1 == x2 αλλά y1 != y2, η ευθεία είναι κάθετη
            print("\nΗ ευθεία είναι κάθετη (παράλληλη στον άξονα y).")
            print("Η κλίση της δεν ορίζεται (αδύνατη η διαίρεση με το μηδέν).")
    else:
        # 3. Υπολογισμός και εκτύπωση της κλίσης
        slope = (y2 - y1) / (x2 - x1)
        print(f"\nΗ κλίση της ευθείας είναι: {slope:.4f}")

if __name__ == "__main__":
    main()
```


4. **Μήκος σκάλας**  
   Δίνονται ύψος τοίχου $h$ (μέτρα) και γωνία κλίσης σκάλας $\theta$ (μοίρες). Υπολογίστε το μήκος σκάλας $L = h / \sin(\theta_{\text{rad}})$, με $\theta_{\text{rad}} = \theta \cdot \pi/180$.  
   *(Απάντηση: $h=5$ m, $\theta=30^\circ$ → $L \approx 10.0$ m)*

```python
import math

def main():
    print("Υπολογισμός Μήκους Σκάλας")
    print("--------------------------")
    
    try:
        # 1. Εισαγωγή δεδομένων από τον χρήστη
        h = float(input("Δώστε το ύψος του τοίχου h (σε μέτρα): "))
        theta = float(input("Δώστε τη γωνία κλίσης θ (σε μοίρες): "))
    except ValueError:
        print("Σφάλμα: Παρακαλώ εισάγετε έγκυρους αριθμούς.")
        return

    # 2. Έλεγχος εγκυρότητας των δεδομένων εισόδου
    if h <= 0:
        print("Σφάλμα: Το ύψος του τοίχου πρέπει να είναι θετικός αριθμός.")
        return
        
    # Για μια σκάλα που ακουμπά σε τοίχο, η γωνία πρέπει λογικά να είναι μεταξύ 0 και 90 μοιρών
    if theta <= 0 or theta >= 90:
        print("Σφάλμα: Η γωνία κλίσης πρέπει να είναι μεγαλύτερη από 0° και μικρότερη από 90°.")
        return

    # 3. Μετατροπή της γωνίας από μοίρες σε ακτίνια (radians)
    # Οι τριγωνομετρικές συναρτήσεις της Python (όπως η math.sin) δέχονται μόνο ακτίνια
    theta_rad = theta * (math.pi / 180)
    
    # Εναλλακτικά, η Python παρέχει την έτοιμη συνάρτηση:
    # theta_rad = math.radians(theta)

    # 4. Υπολογισμός του μήκους της σκάλας (L)
    ladder_length = h / math.sin(theta_rad)

    # 5. Εκτύπωση αποτελέσματος
    print(f"\nΓια ύψος τοίχου h = {h:.2f} m και γωνία κλίσης θ = {theta:.1f}°:")
    print(f"Το απαιτούμενο μήκος της σκάλας είναι L = {ladder_length:.2f} μέτρα.")

if __name__ == "__main__":
    main()
```

5. **Μέθοδος Νεύτωνα για τετραγωνική ρίζα**  
   Για $x>0$, ξεκινήστε με $guess = x/2$ και εφαρμόστε $N$ φορές τον τύπο $guess = \frac{guess + x/guess}{2}$. Συγκρίνετε το αποτέλεσμα με `math.sqrt(x)`. Δοκιμάστε $x=2$, $N=5$.  
   *(Απάντηση: μετά από 5 επαναλήψεις το σφάλμα είναι μικρότερο από $10^{-15}$)*

```python
import math

def newton_sqrt(x, iterations):
    # Αρχική πρόβλεψη (guess) = x / 2
    guess = x / 2.0
    print(f"Αρχική τιμή (guess): {guess:.15f}")
    
    for i in range(1, iterations + 1):
        # Εφαρμογή του τύπου: guess = (guess + x/guess) / 2
        guess = (guess + x / guess) / 2.0
        print(f"Επανάληψη {i}: guess = {guess:.15f}")
        
    return guess

def main():
    x = 2.0
    N = 5
    
    print(f"Υπολογισμός τετραγωνικής ρίζας του {x} με τη μέθοδο Νεύτωνα")
    print("-" * 65)
    
    # 1. Υπολογισμός με τη μέθοδο Νεύτωνα
    approx_sqrt = newton_sqrt(x, N)
    
    # 2. Υπολογισμός με τη συνάρτηση της Python
    actual_sqrt = math.sqrt(x)
    
    # 3. Υπολογισμός απόλυτου σφάλματος
    error = abs(approx_sqrt - actual_sqrt)
    
    print("-" * 65)
    print(f"Προσέγγιση Νεύτωνα (μετά από {N} βήματα): {approx_sqrt:.15f}")
    print(f"Ακριβής τιμή (math.sqrt):             {actual_sqrt:.15f}")
    print(f"Απόλυτο σφάλμα:                        {error:.2e}")

if __name__ == "__main__":
    main()
```
